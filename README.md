<h3>Course Objective:</h3>
<hr>
<li><ul>The goal of the course is to teach students how to analyze algorithms and their complexity. Additionally, it permits the growth of C++ programming language data structures, such as Abstract Data types, Linked Lists, Stacks, Queues, Trees, and Graphs. Additionally, evaluate the effectiveness of the different algorithms offered using mathematical methods, as well as
the typical data structure operations that were covered. Additionally, the course enables students to apply algorithms and
Use the C++ programming language to measure and analyze real-world system performance. The goal of this course is to
help achieve SDG 9: Industry, Innovation, and Infrastructure.</ul></li>
<br>
<br>

## Course Intended Learning Outcomes
<ol>
  <li>Apply fundamental data structures
and techniques to solve
engineering-related problems
through algorithm design</li>
  <li>Design efficient algorithms and
analyze their complexity.</li>
  <li>Build efficient algorithms based on
selected data structures using
good programming styles in C++</li>
</ol>
