# CPE-010-Data-Structures-and-Algorithms-Condino
<h2> Condino,Niel Vincent B.</h2>
<h2>

The goal of the course is to teach students how to analyze algorithms and their complexity. Additionally, it permits the growth of C++ programming language data structures, such as Abstract Data types, Linked Lists, Stacks, Queues, Trees, and Graphs. Additionally, evaluate the effectiveness of the different algorithms offered using mathematical methods, as well as
the typical data structure operations that were covered. Additionally, the course enables students to apply algorithms and
Use the C++ programming language to measure and analyze real-world system performance. The goal of this course is to
help achieve SDG 9: Industry, Innovation, and Infrastructure.
